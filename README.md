# Portfolio

My personal portfolio site.

## Stack

- React 19
- Vite
- Framer Motion
- Tailwind CSS v4

## Development

```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```

## Structure

```
src/
├── config/          # Site content and settings
├── sections/        # Main page sections
├── components/ui/   # Reusable components
└── hooks/           # React hooks
```
